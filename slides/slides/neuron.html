[Zyik, about 45 s] Start from the Week 2 dot product. A single neuron takes the input vector x, takes a dot product with its weight vector w, adds a bias b, then applies a fixed function phi. Geometrically, w-transpose-x plus b equals zero is a line in 2D, a hyperplane in general; w is perpendicular to it, and b shifts it. So before phi, a neuron answers one question: which side of my line is this point on, and how far? Note the line is a shifted copy of the null space of w-transpose, Week 9. We avoid sigma for the activation because sigma means singular value in our course notation.
