[Voon, about 55 s] The fix is a bend applied to each entry separately. The four common choices are plotted, with their derivatives dashed: identity, logistic (often called sigmoid), tanh and ReLU. ReLU keeps scaling by a non-negative number but breaks additivity, so it is not linear, and the collapse argument no longer goes through. Why XOR works: our first-layer matrix has rank 1, its null space is spanned by [1, -1], so both hidden neurons only see s = x1 + x2. The output is ReLU(s) minus 2 ReLU(s minus 1), which gives 0, 1, 0 at s = 0, 1, 2: a tent. A straight line in s can never go up and then down, so no affine model can do this. Notice the logistic derivative never exceeds one quarter; that matters on slide 12.
