[Zhe An, about 55 s] Backpropagation is the chain rule written with matrices, and it is the forward diagram run in reverse. Define delta for layer l as the derivative of the loss with respect to that layer's pre-activation z. At the output with a linear output and squared loss, delta is just y-hat minus y. To move back one layer we do two things. First multiply by W transpose: forward, z = W a has Jacobian W, and for a scalar loss the gradient travels back through the Jacobian transposed, Week 3. Shapes confirm it: W2 is 1 by 2, so W2-transpose is 2 by 1 and turns a 1-number error into a 2-entry error. Second, take the Hadamard product with phi-prime of z, because phi acts entry by entry, so its Jacobian is diagonal, and a diagonal matrix times a vector is an element-wise product. On our numbers we use x = [1, 1] with target 0, after changing W2 to [1, -1] so the network is wrong: y-hat is 1, delta-2 is 1, W2-transpose times 1 is [1, -1], ReLU-prime is [1, 1] since both z entries are positive, so delta-1 is [1, -1].
